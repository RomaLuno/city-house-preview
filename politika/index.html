1. Общие положения

Настоящая Политика обработки персональных данных (далее — Политика) определяет порядок обработки и защиты персональных данных пользователей сайта.

Использование сайта и отправка форм означают согласие пользователя с настоящей Политикой. Пользователь, не согласный с её условиями, не отправляет формы и не пользуется сервисами сайта.

Политика распространяется на персональные данные, полученные до и после даты её публикации.

2. Какие данные обрабатываются

Оператор обрабатывает персональные данные, которые пользователь указывает сам при заполнении формы заявки:

  • имя;
  • номер телефона;
  • мессенджер, в который прислать документы, если выбран этот способ;
  • тема заявки: экскурсия, проект дома или документы по участку.

Вместе с заявкой передаются служебные сведения о её источнике: адрес страницы, с которой отправлена форма, и метки источника перехода (UTM-метки и аналогичные параметры ссылки).

При посещении сайта автоматически обрабатываются обезличенные данные: файлы cookie, IP-адрес, сведения о браузере и устройстве, страницах просмотра и источнике перехода. Эти данные собираются средствами сервиса веб-аналитики Яндекс Метрика и используются для статистики посещаемости и улучшения сайта.

Файлы cookie пользователь может отключить в настройках браузера. Часть функций сайта при этом может работать некорректно.

Оператор не обрабатывает специальные категории персональных данных и биометрические персональные данные.

Оператор не проверяет достоверность указанных пользователем данных и исходит из того, что пользователь предоставляет достоверные сведения и данные только о себе.

3. Цели обработки

Персональные данные обрабатываются в следующих целях:

  • ответ на заявку, отправленную через форму сайта, и связь с пользователем выбранным им способом;
  • консультация по домам и участкам, организация экскурсии на объект и отправка документов по запросу пользователя;
  • заключение и исполнение договора с пользователем.

Обезличенные данные веб-аналитики обрабатываются для статистики и оценки работы сайта и рекламы.

Оператор не использует персональные данные для рассылок, не связанных с заявкой пользователя, и не принимает на их основании решений, порождающих юридические последствия, исключительно автоматизированной обработкой.

4. Правовое основание

Правовое основание обработки — согласие субъекта персональных данных на обработку его персональных данных. Согласие даётся пользователем при отправке формы: отметка в поле «Согласен на обработку персональных данных» и нажатие кнопки отправки.

Для данных, обрабатываемых в целях заключения и исполнения договора, основанием также является договор, стороной которого является пользователь.

В случаях, прямо предусмотренных законодательством Российской Федерации, обработка ведётся на основании соответствующих норм закона.

5. Порядок и место обработки

Обработка включает сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, блокирование, удаление и уничтожение персональных данных. Обработка ведётся с использованием средств автоматизации и без их использования.

Сбор, запись, систематизация, накопление, хранение, уточнение и извлечение персональных данных граждан Российской Федерации осуществляются с использованием баз данных, находящихся на территории Российской Федерации.

6. Срок хранения и уничтожение

Персональные данные хранятся не дольше, чем этого требуют цели обработки, если иной срок не установлен законом или договором.

Заявки хранятся до достижения целей обработки, но не дольше 3 лет с даты заявки. После отзыва согласия данные уничтожаются в течение 30 дней.

Достижение целей обработки, отзыв согласия или требование пользователя об уничтожении данных прекращают обработку. Персональные данные уничтожаются, если их хранение не требуется по закону или для исполнения заключённого договора.

Уничтожение персональных данных подтверждается документально.

Обезличенные данные веб-аналитики хранятся в сервисе Яндекс Метрика в соответствии с условиями этого сервиса.

  • в объёме, необходимом для исполнения договора с пользователем, если без такой передачи его исполнение невозможно;
  • с отдельного согласия пользователя.

Трансграничная передача персональных данных не осуществляется.
